Nessie Executor

Teams

Add a team to choose its folders and commands.

Folders

Nessie can read these folders and prepare file changes for you to approve. Terminal programs keep their own file access.

Keep at least one folder. To end this team’s access, remove the team on Teams.

Nessie can read these conversations and send them instructions. Turning this off leaves them running.

Commands

Add at least one allowed command.

One command per line, for example git status. End a line with * to include anything after it, for example git push *. Blocked commands win.

These rules also decide which programs this team’s agents may start in an interactive terminal on this computer. A program started there runs with your account’s access and can run other commands.
