# Nessie Computer — Windows

[Instalarea Nessie Computer](Install-Nessie-Computer.md)

[Descărcări: `NessieExecutor_1.1.0_x64.msi`](https://github.com/UnlikeOtherAI/nessie-computer/releases)

Necesită Windows 10 22H2 sau mai nou, x64. Deschideți MSI, aprobați instalarea și deschideți Nessie Computer din Start. Pictograma poate fi printre pictogramele ascunse din zona de notificare.

Folosiți codul din aplicație pentru a adăuga computerul la echipa dorită în Nessie. Verificați permisiunile înainte ca agenții să lucreze.
