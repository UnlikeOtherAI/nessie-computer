# Nessie Computer — macOS

[Nessie Computer instalēšana](Install-Nessie-Computer.md)

[Lejupielādes: `Nessie-Computer-macOS-Apple-Silicon.dmg`](https://github.com/UnlikeOtherAI/nessie-computer/releases/latest/download/Nessie-Computer-macOS-Apple-Silicon.dmg)

Nepieciešams Apple silicon un macOS 15 vai jaunāka versija. Atveriet DMG, ievelciet Nessie Computer mapē Applications un atveriet to. Pēc pieprasījuma sistēmas iestatījumos atļaujiet fona palīgpakalpojumu.

Izmantojiet lietotnē redzamo kodu, lai pievienotu datoru vēlamajai Nessie komandai. Pārbaudiet piekļuves atļaujas, pirms aģenti sāk darbu.

Pirms atjaunināšanas ļaujiet darbam pabeigties un aizveriet vecākās Nessie Desktop kopijas. Palīgpakalpojums mēģinās vēlreiz automātiski. Pirms Desktop atkārtotas atvēršanas pārbaudiet instalēto versiju iestatījumos un ar `nessie-computer --version`; tikai lietotnes nomaiņa neapstiprina izpildvides atjaunināšanu.
