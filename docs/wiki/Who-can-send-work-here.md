# Who can send work here

Each team card on **Overview** has a **Who can send work here** section. It
lists the agents, people and projects in that team that may give this computer
work. Nessie decides this; the computer shows it so you can see it beside what
the team can use.

Example:

> **Who can send work here**
> Agents: Sales agent, Project Manager
> People: you, and everyone in Sales
> Projects: Website relaunch
> [Change in Nessie](#change-who-can-send-work)

The list is read from Nessie when you open the window. It isn't stored on the
computer.

## Change who can send work

Choose **Change in Nessie**. It opens the computer's page in Nessie, where you
can:

- add or remove the agents that may use it,
- share it with particular people, projects or the whole team, or keep it to
  yourself,
- turn it off for now in Nessie.

A new computer is yours alone until you share it.

## Both halves together

An agent can use something on this computer only if **both** sides agree:

1. Nessie lets that agent (or the person it works for) send work here, and
2. this computer allows the folder, program, website or local app it needs.

So sharing a computer in Nessie never gives anyone more than you allowed on the
computer.

## On the command line

```sh
nessie-computer who --team "Sales · Acme"
```
