# Nessie Computer — Windows

[Инсталација Nessie Computer](Install-Nessie-Computer.md)

[Преузимања: `Nessie-Computer-Windows-x64.msi`](https://github.com/UnlikeOtherAI/nessie-computer/releases/latest/download/Nessie-Computer-Windows-x64.msi)

Потребан је Windows 10 22H2 или новији, x64. Отворите MSI, одобрите инсталацију и отворите Nessie Computer из менија Start. Икона може бити међу скривеним иконама области обавештења.

Кодом из апликације додајте рачунар жељеном тиму у Nessie. Проверите дозволе пре него што агенти почну да раде.

Пре одобрења проверите да ли је издавач **UnlikeOtherAI s.r.o.**. После инсталације отворите нови прозор PowerShell-а и проверите инсталирану команду:

```powershell
nessie-computer --version
nessie-computer --help
```
