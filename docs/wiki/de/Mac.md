# Nessie Computer — macOS

[Nessie Computer installieren](Install-Nessie-Computer.md)

[Downloads: `Nessie-Computer-macOS-Apple-Silicon.dmg`](https://github.com/UnlikeOtherAI/nessie-computer/releases/latest/download/Nessie-Computer-macOS-Apple-Silicon.dmg)

Erfordert Apple silicon und macOS 15 oder neuer. Öffnen Sie die DMG-Datei, ziehen Sie Nessie Computer in Programme und öffnen Sie die App. Erlauben Sie bei Aufforderung den Hintergrunddienst in den Systemeinstellungen.

Fügen Sie den Computer mit dem Code aus der App dem gewünschten Team in Nessie hinzu. Prüfen Sie die Zugriffsrechte, bevor Agenten arbeiten.
