# Nessie Computer — Windows

[Инсталирање на Nessie Computer](Install-Nessie-Computer.md)

[Преземања: `Nessie-Computer-Windows-x64.msi`](https://github.com/UnlikeOtherAI/nessie-computer/releases/latest/download/Nessie-Computer-Windows-x64.msi)

Потребен е Windows 10 22H2 или понов, x64. Отворете го MSI, одобрете ја инсталацијата и отворете го Nessie Computer од Start. Иконата може да биде меѓу скриените икони во областа за известувања.

Со кодот од апликацијата додајте го компјутерот во саканиот тим во Nessie. Проверете ги дозволите пред агентите да почнат да работат.
