# Nessie Computer — Windows

[Встановлення Nessie Computer](Install-Nessie-Computer.md)

[Завантаження: `Nessie-Computer-Windows-x64.msi`](https://github.com/UnlikeOtherAI/nessie-computer/releases/latest/download/Nessie-Computer-Windows-x64.msi)

Потрібна Windows 10 22H2 або новіша, x64. Відкрийте MSI, дозвольте встановлення та запустіть Nessie Computer з меню «Пуск». Значок може бути серед прихованих значків області сповіщень.

Використайте код із програми, щоб додати комп’ютер до потрібної команди в Nessie. Перевірте дозволи, перш ніж агенти почнуть працювати.
