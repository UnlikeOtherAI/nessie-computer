# Nessie Computer — Windows

[Instaloni Nessie Computer](Install-Nessie-Computer.md)

[Shkarkime: `NessieExecutor_1.1.0_x64.msi`](https://github.com/UnlikeOtherAI/nessie-computer/releases)

Kërkon Windows 10 22H2 ose më të ri, x64. Hapni MSI, miratoni instalimin dhe hapni Nessie Computer nga Start. Ikona mund të jetë mes ikonave të fshehura në zonën e njoftimeve.

Përdorni kodin nga aplikacioni për ta shtuar kompjuterin në ekipin e dëshiruar në Nessie. Kontrolloni lejet para se agjentët të punojnë.
