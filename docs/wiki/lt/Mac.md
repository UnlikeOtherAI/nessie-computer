# Nessie Computer — macOS

[Įdiegti Nessie Computer](Install-Nessie-Computer.md)

[Atsisiuntimai: `Nessie-Computer-macOS-Apple-Silicon.dmg`](https://github.com/UnlikeOtherAI/nessie-computer/releases/latest/download/Nessie-Computer-macOS-Apple-Silicon.dmg)

Reikia Apple silicon ir macOS 15 arba naujesnės versijos. Atidarykite DMG, nutempkite Nessie Computer į Applications ir paleiskite. Kai prašoma, sistemos nustatymuose leiskite foninę pagalbinę tarnybą.

Programoje rodomu kodu pridėkite kompiuterį prie norimos Nessie komandos. Prieš agentams pradedant darbą patikrinkite prieigos leidimus.

Prieš naujindami palaukite, kol baigsis darbas, ir uždarykite senesnes Nessie Desktop kopijas. Pagalbinė tarnyba bandys dar kartą automatiškai. Prieš vėl atidarydami Desktop, patikrinkite įdiegtą versiją nustatymuose ir komanda `nessie-computer --version`; vien programos pakeitimas nepatvirtina vykdymo aplinkos atnaujinimo.
