# Nessie Computer — macOS

[Εγκατάσταση του Nessie Computer](Install-Nessie-Computer.md)

[Λήψεις: `NessieExecutor_1.1.0_arm64.dmg`](https://github.com/UnlikeOtherAI/nessie-computer/releases)

Απαιτεί Apple silicon και macOS 15 ή νεότερο. Ανοίξτε το DMG, σύρετε το Nessie Computer στις Εφαρμογές και ανοίξτε το. Όταν ζητηθεί, επιτρέψτε τη βοηθητική υπηρεσία παρασκηνίου στις Ρυθμίσεις συστήματος.

Χρησιμοποιήστε τον κωδικό της εφαρμογής για να προσθέσετε τον υπολογιστή στην επιθυμητή ομάδα στο Nessie. Ελέγξτε τα δικαιώματα πριν εργαστούν οι πράκτορες.
