# Nessie Computer — Windows

[Εγκατάσταση του Nessie Computer](Install-Nessie-Computer.md)

[Λήψεις: `NessieExecutor_1.1.0_x64.msi`](https://github.com/UnlikeOtherAI/nessie-computer/releases)

Απαιτεί Windows 10 22H2 ή νεότερο, x64. Ανοίξτε το MSI, εγκρίνετε την εγκατάσταση και ανοίξτε το Nessie Computer από την Έναρξη. Το εικονίδιο μπορεί να βρίσκεται στα κρυφά εικονίδια της περιοχής ειδοποιήσεων.

Χρησιμοποιήστε τον κωδικό της εφαρμογής για να προσθέσετε τον υπολογιστή στην επιθυμητή ομάδα στο Nessie. Ελέγξτε τα δικαιώματα πριν εργαστούν οι πράκτορες.
