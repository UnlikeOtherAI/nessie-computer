# Nessie Computer — Windows

[Nessie Computer 설치](Install-Nessie-Computer.md)

[다운로드: `Nessie-Computer-Windows-x64.msi`](https://github.com/UnlikeOtherAI/nessie-computer/releases/latest/download/Nessie-Computer-Windows-x64.msi)

Windows 10 22H2 이상, x64가 필요합니다. MSI를 열고 설치를 승인한 다음 시작 메뉴에서 Nessie Computer를 실행하세요. 아이콘은 알림 영역의 숨겨진 아이콘에 있을 수 있습니다.

앱에 표시된 코드를 사용해 컴퓨터를 Nessie의 원하는 팀에 추가하세요. 에이전트가 작업하기 전에 접근 권한을 검토하세요.

승인하기 전에 게시자가 **UnlikeOtherAI s.r.o.**인지 확인하세요. 설치 후 새 PowerShell 창을 열고 설치된 명령을 확인하세요.

```powershell
nessie-computer --version
nessie-computer --help
```
