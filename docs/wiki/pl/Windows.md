# Nessie Computer — Windows

[Instalacja Nessie Computer](Install-Nessie-Computer.md)

[Pliki do pobrania: `Nessie-Computer-Windows-x64.msi`](https://github.com/UnlikeOtherAI/nessie-computer/releases/latest/download/Nessie-Computer-Windows-x64.msi)

Wymaga Windows 10 22H2 lub nowszego, x64. Otwórz MSI, zatwierdź instalację i uruchom Nessie Computer z menu Start. Ikona może być wśród ukrytych ikon obszaru powiadomień.

Użyj kodu z aplikacji, aby dodać komputer do właściwego zespołu w Nessie. Sprawdź uprawnienia, zanim agenci rozpoczną pracę.

Przed zatwierdzeniem sprawdź, czy wydawcą jest **UnlikeOtherAI s.r.o.**. Po instalacji otwórz nowe okno PowerShell i sprawdź zainstalowane polecenie:

```powershell
nessie-computer --version
nessie-computer --help
```
