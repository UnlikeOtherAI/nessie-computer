# Nessie Computer — Windows

[Instalacija Nessie Computer](Install-Nessie-Computer.md)

[Preuzimanja: `Nessie-Computer-Windows-x64.msi`](https://github.com/UnlikeOtherAI/nessie-computer/releases/latest/download/Nessie-Computer-Windows-x64.msi)

Potreban je Windows 10 22H2 ili noviji, x64. Otvorite MSI, odobrite instalaciju i otvorite Nessie Computer iz izbornika Start. Ikona može biti među skrivenim ikonama područja obavijesti.

Kod iz aplikacije upotrijebite za dodavanje računala željenom timu u Nessie. Provjerite dopuštenja prije nego što agenti počnu raditi.

Prije odobrenja provjerite je li izdavač **UnlikeOtherAI s.r.o.**. Nakon instalacije otvorite novi prozor PowerShella i provjerite instaliranu naredbu:

```powershell
nessie-computer --version
nessie-computer --help
```
