# Nessie Computer — macOS

[Installer Nessie Computer](Install-Nessie-Computer.md)

[Téléchargements: `Nessie-Computer-macOS-Apple-Silicon.dmg`](https://github.com/UnlikeOtherAI/nessie-computer/releases/latest/download/Nessie-Computer-macOS-Apple-Silicon.dmg)

Nécessite une puce Apple et macOS 15 ou ultérieur. Ouvrez le DMG, glissez Nessie Computer dans Applications, puis ouvrez l’application. Autorisez le service en arrière-plan dans Réglages Système si cela vous est demandé.

Utilisez le code affiché dans l’application pour ajouter cet ordinateur à l’équipe souhaitée dans Nessie. Vérifiez les autorisations avant de laisser travailler les agents.
