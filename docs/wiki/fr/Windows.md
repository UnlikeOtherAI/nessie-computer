# Nessie Computer — Windows

[Installer Nessie Computer](Install-Nessie-Computer.md)

[Téléchargements: `Nessie-Computer-Windows-x64.msi`](https://github.com/UnlikeOtherAI/nessie-computer/releases/latest/download/Nessie-Computer-Windows-x64.msi)

Nécessite Windows 10 22H2 ou ultérieur, x64. Ouvrez le MSI, autorisez l’installation, puis ouvrez Nessie Computer depuis Démarrer. Son icône peut se trouver parmi les icônes masquées de la zone de notification.

Utilisez le code affiché dans l’application pour ajouter cet ordinateur à l’équipe souhaitée dans Nessie. Vérifiez les autorisations avant de laisser travailler les agents.

Avant de confirmer, vérifiez que l’éditeur est **UnlikeOtherAI s.r.o.**. Après l’installation, ouvrez une nouvelle fenêtre PowerShell et vérifiez la commande installée :

```powershell
nessie-computer --version
nessie-computer --help
```
