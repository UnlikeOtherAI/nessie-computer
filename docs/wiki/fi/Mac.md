# Nessie Computer — macOS

[Asenna Nessie Computer](Install-Nessie-Computer.md)

[Lataukset: `Nessie-Computer-macOS-Apple-Silicon.dmg`](https://github.com/UnlikeOtherAI/nessie-computer/releases/latest/download/Nessie-Computer-macOS-Apple-Silicon.dmg)

Vaatii Apple siliconin ja macOS 15:n tai uudemman. Avaa DMG, vedä Nessie Computer Ohjelmat-kansioon ja avaa se. Salli taustalla toimiva apupalvelu Järjestelmäasetuksissa pyydettäessä.

Lisää tietokone haluamaasi Nessie-tiimiin sovelluksen näyttämällä koodilla. Tarkista käyttöoikeudet ennen agenttien työskentelyä.

Anna käynnissä olevien töiden valmistua ja sulje vanhemmat Nessie Desktop -sovellukset ennen päivitystä. Apupalvelu yrittää automaattisesti uudelleen. Tarkista asennettu versio asetuksista ja komennolla `nessie-computer --version` ennen Desktopin avaamista; pelkkä sovelluksen vaihtaminen ei vahvista suoritusympäristön päivittyneen.
