# Nessie Computer — Windows

[Asenna Nessie Computer](Install-Nessie-Computer.md)

[Lataukset: `NessieExecutor_1.1.0_x64.msi`](https://github.com/UnlikeOtherAI/nessie-computer/releases)

Vaatii Windows 10 22H2:n tai uudemman, x64. Avaa MSI, hyväksy asennus ja avaa Nessie Computer Käynnistä-valikosta. Kuvake voi olla ilmaisinalueen piilotettujen kuvakkeiden joukossa.

Lisää tietokone haluamaasi Nessie-tiimiin sovelluksen näyttämällä koodilla. Tarkista käyttöoikeudet ennen agenttien työskentelyä.
