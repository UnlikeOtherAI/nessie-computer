# Nessie Computer — Windows

[Install Nessie Computer](Install-Nessie-Computer.md)

[Downloads: `NessieExecutor_1.1.0_x64.msi`](https://github.com/UnlikeOtherAI/nessie-computer/releases)

Requires Windows 10 22H2 or later, x64. Open the MSI, approve the installer, then open Nessie Computer from Start. Its icon may be under the notification area's hidden icons.

Use the code shown in the app to add this computer to the intended team in Nessie. Review access before letting agents work.
