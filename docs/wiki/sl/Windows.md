# Nessie Computer — Windows

[Namestitev Nessie Computer](Install-Nessie-Computer.md)

[Prenosi: `NessieExecutor_1.1.0_x64.msi`](https://github.com/UnlikeOtherAI/nessie-computer/releases)

Zahteva Windows 10 22H2 ali novejši, x64. Odprite MSI, odobrite namestitev in odprite Nessie Computer iz menija Start. Ikona je lahko med skritimi ikonami območja za obvestila.

S kodo iz aplikacije dodajte računalnik želeni ekipi v Nessie. Preden agenti začnejo delati, preverite dovoljenja.
