# Nessie Computer — Windows

[Suiteáil Nessie Computer](Install-Nessie-Computer.md)

[Íoslódálacha: `Nessie-Computer-Windows-x64.msi`](https://github.com/UnlikeOtherAI/nessie-computer/releases/latest/download/Nessie-Computer-Windows-x64.msi)

Teastaíonn Windows 10 22H2 nó níos nuaí, x64. Oscail an MSI, ceadaigh an tsuiteáil agus oscail Nessie Computer ó Start. D’fhéadfadh an deilbhín a bheith i measc dheilbhíní folaithe an limistéir fógraí.

Úsáid an cód san aip chun an ríomhaire a chur leis an bhfoireann atá uait in Nessie. Seiceáil na ceadanna sula dtosaíonn na gníomhairí ag obair.

Sula gceadaíonn tú an tsuiteáil, deimhnigh gurb é **UnlikeOtherAI s.r.o.** an foilsitheoir. Tar éis na suiteála, oscail fuinneog nua PowerShell agus seiceáil an t-ordú suiteáilte:

```powershell
nessie-computer --version
nessie-computer --help
```

Sula ndéanann tú nuashonrú, lig don obair atá ar siúl críochnú agus fág Nessie Computer ar oscailt. Atosaíonn an suiteálaí an aip agus ní bhaineann sé seanghlasanna nasc go dtí go ndeimhníonn Windows go bhfuil deireadh leis an bpróiseas bunaidh. Coinnítear socruithe agus stair na bhfoirne.
