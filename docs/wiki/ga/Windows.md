# Nessie Computer — Windows

[Suiteáil Nessie Computer](Install-Nessie-Computer.md)

[Íoslódálacha: `NessieExecutor_1.1.0_x64.msi`](https://github.com/UnlikeOtherAI/nessie-computer/releases)

Teastaíonn Windows 10 22H2 nó níos nuaí, x64. Oscail an MSI, ceadaigh an tsuiteáil agus oscail Nessie Computer ó Start. D’fhéadfadh an deilbhín a bheith i measc dheilbhíní folaithe an limistéir fógraí.

Úsáid an cód san aip chun an ríomhaire a chur leis an bhfoireann atá uait in Nessie. Seiceáil na ceadanna sula dtosaíonn na gníomhairí ag obair.
