# Nessie Computer — Windows

[Installare Nessie Computer](Install-Nessie-Computer.md)

[Download: `NessieExecutor_1.1.0_x64.msi`](https://github.com/UnlikeOtherAI/nessie-computer/releases)

Richiede Windows 10 22H2 o successivo, x64. Apri il MSI, autorizza l’installazione e apri Nessie Computer da Start. L’icona potrebbe trovarsi tra quelle nascoste nell’area di notifica.

Usa il codice mostrato nell’app per aggiungere il computer al team desiderato in Nessie. Controlla i permessi prima che gli agenti lavorino.
