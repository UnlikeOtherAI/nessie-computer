# Nessie Computer — macOS

[Nessie Computer のインストール](Install-Nessie-Computer.md)

[ダウンロード: `Nessie-Computer-macOS-Apple-Silicon.dmg`](https://github.com/UnlikeOtherAI/nessie-computer/releases/latest/download/Nessie-Computer-macOS-Apple-Silicon.dmg)

Apple silicon と macOS 15 以降が必要です。DMG を開き、Nessie Computer を「アプリケーション」にドラッグして起動します。確認が表示されたら、システム設定でバックグラウンドの補助サービスを許可してください。

アプリに表示されたコードを使って、Nessie の目的のチームにこのコンピューターを追加します。エージェントが作業する前にアクセス権限を確認してください。

アップグレード前に実行中の作業が終わるのを待ち、古い Nessie Desktop を終了してください。補助サービスは自動的に再試行します。Desktop を再び開く前に、設定のインストール済みバージョンと `nessie-computer --version` を確認してください。アプリを置き換えただけでは、ランタイムの更新が完了したとは限りません。
