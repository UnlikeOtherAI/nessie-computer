# Nessie Computer — Windows

[Instal Nessie Computer](Install-Nessie-Computer.md)

[Unduhan: `Nessie-Computer-Windows-x64.msi`](https://github.com/UnlikeOtherAI/nessie-computer/releases/latest/download/Nessie-Computer-Windows-x64.msi)

Memerlukan Windows 10 22H2 atau lebih baru, x64. Buka MSI, setujui instalasi, lalu buka Nessie Computer dari Start. Ikonnya mungkin berada di antara ikon tersembunyi di area notifikasi.

Gunakan kode di aplikasi untuk menambahkan komputer ke tim yang diinginkan di Nessie. Tinjau izin akses sebelum agen bekerja.

Sebelum menyetujui, pastikan penerbitnya adalah **UnlikeOtherAI s.r.o.**. Setelah instalasi, buka jendela PowerShell baru dan periksa perintah yang terpasang:

```powershell
nessie-computer --version
nessie-computer --help
```
