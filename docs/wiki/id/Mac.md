# Nessie Computer — macOS

[Instal Nessie Computer](Install-Nessie-Computer.md)

[Unduhan: `Nessie-Computer-macOS-Apple-Silicon.dmg`](https://github.com/UnlikeOtherAI/nessie-computer/releases/latest/download/Nessie-Computer-macOS-Apple-Silicon.dmg)

Memerlukan Apple silicon dan macOS 15 atau lebih baru. Buka DMG, seret Nessie Computer ke Applications, lalu buka. Izinkan layanan pembantu di latar belakang melalui Pengaturan Sistem saat diminta.

Gunakan kode di aplikasi untuk menambahkan komputer ke tim yang diinginkan di Nessie. Tinjau izin akses sebelum agen bekerja.

Sebelum memperbarui, tunggu pekerjaan selesai dan tutup salinan Nessie Desktop yang lama. Layanan pembantu akan mencoba lagi secara otomatis. Sebelum membuka Desktop kembali, periksa versi terinstal di Pengaturan dan jalankan `nessie-computer --version`; mengganti aplikasi saja tidak membuktikan bahwa runtime telah diperbarui.
