# Nessie Computer — macOS

[Nessie Computer इंस्टॉल करें](Install-Nessie-Computer.md)

[डाउनलोड: `Nessie-Computer-macOS-Apple-Silicon.dmg`](https://github.com/UnlikeOtherAI/nessie-computer/releases/latest/download/Nessie-Computer-macOS-Apple-Silicon.dmg)

Apple silicon और macOS 15 या नया संस्करण चाहिए। DMG खोलें, Nessie Computer को Applications में खींचें और खोलें। पूछे जाने पर सिस्टम सेटिंग्स में बैकग्राउंड सहायक सेवा को अनुमति दें।

ऐप में दिखाए गए कोड से इस कंप्यूटर को Nessie की इच्छित टीम में जोड़ें। एजेंटों को काम करने देने से पहले अनुमतियाँ जाँचें।

अपडेट से पहले चल रहा काम पूरा होने दें और Nessie Desktop की पुरानी प्रतियाँ बंद करें। सहायक सेवा अपने आप दोबारा कोशिश करती है। Desktop फिर खोलने से पहले सेटिंग्स में इंस्टॉल किया गया संस्करण जाँचें और `nessie-computer --version` चलाएँ; केवल ऐप बदलने से रनटाइम का अपडेट होना साबित नहीं होता।
