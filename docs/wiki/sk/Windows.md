# Nessie Computer — Windows

[Inštalácia Nessie Computer](Install-Nessie-Computer.md)

[Na stiahnutie: `Nessie-Computer-Windows-x64.msi`](https://github.com/UnlikeOtherAI/nessie-computer/releases/latest/download/Nessie-Computer-Windows-x64.msi)

Vyžaduje Windows 10 22H2 alebo novší, x64. Otvorte MSI, povoľte inštaláciu a spustite Nessie Computer z ponuky Štart. Ikona môže byť medzi skrytými ikonami oblasti oznámení.

Pomocou kódu z aplikácie pridajte počítač do požadovaného tímu v Nessie. Pred prácou agentov skontrolujte oprávnenia.

Pred potvrdením overte, že vydavateľom je **UnlikeOtherAI s.r.o.**. Po inštalácii otvorte nové okno PowerShellu a overte nainštalovaný príkaz:

```powershell
nessie-computer --version
nessie-computer --help
```
