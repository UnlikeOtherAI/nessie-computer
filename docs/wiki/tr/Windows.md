# Nessie Computer — Windows

[Nessie Computer kurulumu](Install-Nessie-Computer.md)

[İndirmeler: `Nessie-Computer-Windows-x64.msi`](https://github.com/UnlikeOtherAI/nessie-computer/releases/latest/download/Nessie-Computer-Windows-x64.msi)

Windows 10 22H2 veya üzeri, x64 gerekir. MSI dosyasını açın, kurulumu onaylayın ve Başlat’tan Nessie Computer’ı açın. Simge, bildirim alanının gizli simgeleri arasında olabilir.

Uygulamadaki kodu kullanarak bilgisayarı Nessie’de istediğiniz takıma ekleyin. Ajanlar çalışmadan önce erişim izinlerini gözden geçirin.

Onaylamadan önce yayıncının **UnlikeOtherAI s.r.o.** olduğunu doğrulayın. Kurulumdan sonra yeni bir PowerShell penceresi açın ve yüklenen komutu kontrol edin:

```powershell
nessie-computer --version
nessie-computer --help
```
