# Nessie Computer — Windows

[Instalace Nessie Computer](Install-Nessie-Computer.md)

[Ke stažení: `Nessie-Computer-Windows-x64.msi`](https://github.com/UnlikeOtherAI/nessie-computer/releases/latest/download/Nessie-Computer-Windows-x64.msi)

Vyžaduje Windows 10 22H2 nebo novější, x64. Otevřete MSI, potvrďte instalaci a spusťte Nessie Computer z nabídky Start. Ikona může být mezi skrytými ikonami oznamovací oblasti.

Pomocí kódu z aplikace přidejte počítač do požadovaného týmu v Nessie. Než agenti začnou pracovat, zkontrolujte oprávnění.
