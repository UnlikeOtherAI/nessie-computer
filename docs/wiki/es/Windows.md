# Nessie Computer — Windows

[Instalar Nessie Computer](Install-Nessie-Computer.md)

[Descargas: `Nessie-Computer-Windows-x64.msi`](https://github.com/UnlikeOtherAI/nessie-computer/releases/latest/download/Nessie-Computer-Windows-x64.msi)

Requiere Windows 10 22H2 o posterior, x64. Abra el MSI, autorice la instalación y abra Nessie Computer desde Inicio. El icono puede estar entre los iconos ocultos del área de notificación.

Use el código de la aplicación para añadir este ordenador al equipo deseado en Nessie. Revise los permisos antes de que trabajen los agentes.

Antes de aprobar, comprueba que el editor sea **UnlikeOtherAI s.r.o.**. Tras la instalación, abre una nueva ventana de PowerShell y verifica el comando instalado:

```powershell
nessie-computer --version
nessie-computer --help
```
