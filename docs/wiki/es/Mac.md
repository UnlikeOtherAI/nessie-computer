# Nessie Computer — macOS

[Instalar Nessie Computer](Install-Nessie-Computer.md)

[Descargas: `Nessie-Computer-macOS-Apple-Silicon.dmg`](https://github.com/UnlikeOtherAI/nessie-computer/releases/latest/download/Nessie-Computer-macOS-Apple-Silicon.dmg)

Requiere Apple silicon y macOS 15 o posterior. Abra el DMG, arrastre Nessie Computer a Aplicaciones y ábralo. Cuando se solicite, permita el servicio en segundo plano en Ajustes del Sistema.

Use el código de la aplicación para añadir este ordenador al equipo deseado en Nessie. Revise los permisos antes de que trabajen los agentes.

Antes de actualizar, deje que termine el trabajo y cierre las copias antiguas de Nessie Desktop. El servicio reintenta automáticamente. Antes de volver a abrir Desktop, compruebe la versión instalada en Ajustes y con `nessie-computer --version`; sustituir la aplicación no confirma por sí solo que se haya actualizado el entorno de ejecución.
